# PDF Toolkit

A clean, modular toolkit for reading, writing, inspecting, and manipulating PDF documents with Python and pypdf.

[![Python](https://go-skill-icons.vercel.app/api/icons?i=python)](https://www.python.org/)

## Overview

PDF Toolkit is a Python project for exploring and manipulating PDF documents using `pypdf`.

The project focuses on building a clean and modular API around common PDF operations while also exploring the internal structure of PDF documents.

## Features

- Read PDF documents
- Write and create PDF documents
- Inspect PDF metadata
- Modify document metadata
- Manipulate pages
- Extract and modify document content
- Work with PDF annotations
- Experiment with watermarks
- More coming soon...
